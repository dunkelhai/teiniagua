# Roadmap até a Steam

## Fase 0 — Fatia vertical (feito nesta sessão)
- [x] Projeto Godot 4.7, input de teclado e controle
- [x] Personagem: mover, pular, dash, facão
- [x] Hub com 5 portais
- [x] Chefe 1: Staurikosaurus (investida, salto)
- [x] HUD: vida, barra do chefe, mensagens
- [ ] Som placeholder

## Fase 1 — Sentir o jogo (1–2 semanas)
- Ajustar "game feel": aceleração, pulo, hit-stop, partículas de sangue/poeira
- Pixel art do personagem (idle, run, jump, attack, dash, hurt) no Aseprite
- Pixel art do Staurikosaurus
- Trilha e SFX placeholder (metal instrumental)

## Fase 2 — Os 5 mundos (6–10 semanas)
- Uma fase curta + chefe por mundo, um mundo por ~1,5 semana
- Ordem sugerida: Pampa → Lagoa → Yomi → Pista → Gruta
- Inimigos comuns: 2 por mundo, no máximo

## Fase 3 — Chefe final e fechamento (2–3 semanas)
- Teiniaguá em 3 fases
- Menu, pausa, opções (volume, tela cheia, remapear teclas)
- Save (chefes derrotados) via `user://save.json`
- Localização pt-BR + en

## Fase 4 — Steam (2–3 semanas)
1. Conta Steamworks (taxa de US$100 por jogo, devolvida após US$1.000 em vendas)
2. Página da loja: capsule (capa), 5+ screenshots, trailer de 30–60 s, descrição
3. Integração GodotSteam (conquistas, overlay) — opcional na v1
4. Export Windows/Linux/macOS, upload via SteamPipe
5. Demo pública (Steam Next Fest é a melhor vitrine para indie)
6. Página "coming soon" o mais cedo possível: wishlist é o que importa no lançamento

## Ferramentas
- Godot 4.7 (instalado via Homebrew)
- Aseprite (pixel art, ~US$20) ou LibreSprite (grátis)
- Música: LMMS/Reaper + VSTs, ou contratar
- Git + GitHub
